# 검정·빨강 레이스 뷔스티에 긴팔

사용자가 이 디자인으로 진행하도록 확정했습니다. 캐릭터 착용본 편집 요청은 이미지 도구의 입력 필터에서 거절돼 아직 결과가 없습니다. [현재 상태](../../../docs/vr-woman-black-red-v1/STATUS.md).

기존 흰 키홀넥 상의 제품 시트를 참조해 내장 `image_gen`으로 수정한 의상 단독 디자인입니다. 앞면·뒷면·연결부 확대를 한 장에 담았습니다.

## 반영한 변경

- 목·어깨·가슴 위를 덮던 윗부분 전체 제거.
- 겨드랑이 옆의 좁은 붉은 연결부로만 소매와 몸판 연결.
- 더 깊고 입체적인 컵, 선명한 와이어 곡선과 컵 절개.
- 허리를 강하게 좁힌 롱라인 코르셋, 세로 본 채널, 뒤쪽 조절 끈.
- 검정 꽃무늬 레이스와 짙은 빨강 안감·패널로 배색 변경.
- 컵과 몸판 전반, 소매와 가장자리의 레이스 확대.

컵은 사용자가 요청한 E컵의 풍성한 형태를 디자인 의도로 반영했습니다. 밑가슴 치수·국가별 사이즈 규격이 정해진 실측 패턴은 아닙니다. 인물 착용이나 연결부의 실제 내구성은 검증하지 않았습니다.
