## 디자인 기준

사용자가 정한 내용: 20대 한국인 성인 여성 아바타의 의상. 팬티스타킹, 단화, 스타킹 위에 입는 빨간 레이스 팬티, 허벅지 위쪽 길이의 짧은 치마, 빨간 브라와 어깨끈, 어깨가 드러나는 U넥 흰 시스루 긴팔. 향후 1인칭에서 자신의 몸을 내려다보는 VR 체험용이다.

이 세트에서 정한 보완 사항: 검정 반투명 팬티스타킹, 차콜 A라인 치마, 장식 없는 검정 라운드토 단화, 불투명 안감이 있는 빨간 브라 컵, 좁은 상의 목둘레·소매 마감. 단화 안감은 베이지다. 얼굴과 체형은 아직 디자인하지 않았다.

착용 순서는 하의 안쪽부터 **팬티스타킹 → 빨간 레이스 팬티 → 치마**다. 스타킹은 발끝까지 이어지는 한 벌이며 허벅지 길이의 독립 스타킹이 아니다. 상의는 빨간 브라 위에 흰 시스루를 입는 설정이다.

01번을 전체 실루엣·배색 기준으로 삼고, 02번은 상의, 03번은 이너, 04번은 치마, 05번은 스타킹·신발의 세부 기준으로 사용한다. 06번은 가까이 보이는 재질과 마감의 시각 참고다.

## 확인한 범위와 남은 작업

- 여섯 원본을 직접 보고 색·품목·구성·한글 표기·레이어 순서를 확인했다. 저장 파일의 디코딩·해상도·해시와 ZIP 무결성도 확인한다.
- 최초의 착용 인물 시트 생성은 이미지 도구의 sexual 안전 필터에 의해 거절됐다. 이후 인체 없는 제품 시트로 범위를 바꾸어 위 여섯 장을 제작했다. 착용 인물, 전신 3면도, 1인칭 착용 시점은 포함되지 않는다.
- 시각적 디자인 자료이며 실측 패턴·정확한 다각도 스캔·PBR 텍스처·UV·3D 메시가 아니다. 확대도의 봉제 조직과 원단 배율에는 생성 이미지의 해석 차이가 있다.
- 실제 어깨 노출과 네크라인 깊이, 치마의 허벅지 위쪽 길이는 체형에 맞춘 착용 검토가 남아 있다. 시트만으로 핏을 검증했다고 볼 수 없다.
- VR 적용 단계에는 눈높이의 시야, 내려다보기, 소매와 손목 연결, 의복 겹침, 앉기와 걷기 시 관통·변형, 투명 원단의 렌더링 검토가 필요하다. 이번 작업에서는 3D 생성이나 VR 구현을 실행하지 않았다.

## 제작 기록

외부 작가 이미지나 실존 인물 사진을 사용하지 않았다. 01번을 텍스트로 생성하고 02~05번은 01번을, 06번은 01·03번을 참조했다. 프롬프트 원본은 프로젝트의 `docs/vr-womenswear-v1/`에, 배포 ZIP에서는 `prompts/`에 있다. 이미지 편집용 외부 API나 CLI는 사용하지 않았다. PINOC 생성은 호출하지 않았다.
