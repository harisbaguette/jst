# 단발 여성 캐릭터와 의상 참고 시트

2026-10-21 · 의상 수정본 6장 + 캐릭터 6장 = 총 12장.

`index.html`에서 전체 시트를 보고 원본 이미지를 열 수 있다. PNG 원본과 최종 생성·편집 프롬프트를 ZIP에 함께 넣었다. OpenAI 내장 `image_gen`으로 제작했고, 외부 작가 이미지나 실존 인물 사진을 사용하지 않았다.

## 현재 캐릭터 기준

- 가상의 한국인 **25세 성인 여성**. 성숙하고 세련된 인상, 밝은 아이보리 피부, 자연스러운 피부결과 로즈 톤 입술.
- 턱 바로 아래에서 끝나는 짙은 다크브라운 **단발**. 가벼운 앞머리, 살짝 치우친 가르마, 안쪽으로 말리는 머리끝. 긴 머리 초안은 최종 기준에서 제외했다.
- 사용자가 요청한 글래머러스한 체형: 풍성한 가슴, 잘록한 허리, 넓고 둥근 골반. E컵은 제작 요청의 체형 방향이며, 이미지로 실측 사이즈를 검증한 것은 아니다. 치수는 아직 확정하지 않았다.
- 짧은 타원형 누드핑크 네일. 귀걸이·반지·문신 등 추가 장식 없음.

## 의상과 시트의 우선순위

흰 시스루 긴팔은 앞 U넥을 깊게, 원단을 더 얇고 투명하게 수정했다. 빨간 브라는 컵 전체에 꽃무늬 레이스를 덧대고 윗선을 물결 모양으로 마감한다. 검정 단화는 앞쪽에만 작은 끈 리본을 두고 별도 굽 단차 없는 얇은 밑창으로 만든다. 하의는 팬티스타킹 위에 빨간 레이스 팬티, 그 위에 짧은 차콜 A라인 치마다.

얼굴은 07, 체형은 08, 헤어의 뒤와 가르마는 09를 우선한다. 의상은 각 부위 상세 시트 02·03·04·05를 우선하며, 01은 조합을 보여주는 전체 구성도다. 06·11·12는 가까이 보는 세부의 시각 참고다. AI가 만든 각도의 세부에 차이가 있을 때 정면 기준과 해당 부위 상세 시트를 따른다.

08의 회색 티셔츠와 바지는 **체형 확인용 기본 의상**이다. 최종 의상 착용본이 아니다. 08에 단순화되어 그려진 신발보다 05의 굽 없는 플랫 설계가 우선한다. 12는 손의 재질·형태·제스처 참고이며, 좌우 배치와 관절 회전을 그대로 리깅 값으로 사용하지 않는다.

## 확인 범위

모든 채택 이미지를 직접 보며 단발 길이, 피부 톤, 성인 인상, 체형 실루엣, 주요 의상 변경, 레이어 순서, 표정 차이와 세부 표현을 확인했다. 원본 파일 디코딩·해상도·SHA-256, 목록의 파일 연결과 ZIP 무결성은 별도로 검사한다.

07과 11은 1774×887, 나머지 10장은 1536×1024 PNG다. 3D 스캔이나 실측 패턴이 아니며, 확대도의 원단 배율과 미세 모양에는 생성 이미지의 해석이 들어 있다. 머리카락·레이스·피부결을 그대로 사용할 수 있는 PBR 텍스처나 UV 맵은 아니다.

**남은 작업:** 최종 의상을 입힌 전신, 실제 착용 핏, 1인칭 시야, 3D 생성과 메시·재질·리깅, 걷기·앉기 중 관통, 투명 원단의 렌더링. 이번 단계는 참고 시트 제작이며 해당 구현·검증은 아직 하지 않았다.
