# 단발 여성 · 흰 상의 3D 캐릭터

완성돼 있던 흰 U넥 긴팔·짧은 차콜 치마·검정 팬티스타킹·무굽 리본 플랫 착용 이미지 3장으로 PINOC(JST-2)에서 생성한 캐릭터입니다. 검정·빨강 뷔스티에 착용본이 아닙니다.

## 파일과 사용

- `characters/vr-woman-opaque.vsplat`: 캐릭터 본체. `high`, 48,000 Gaussian.
- `motions/idle.glb`, `walk.glb`, `run.glb`: 기존 무료 대기·걷기·달리기 동작.
- `references/`: 생성에 실제 사용한 정면·측면·후면 원본 PNG.
- `generation.json`: 입력·생성 조건·비용·자산 ID·파일 해시.
- `verification.json`: 실제 뷰어 기능 검사 결과.

현재 PC에서는 [로컬 뷰어](http://127.0.0.1:5178/?model=vr-opaque)를 엽니다. 서버가 꺼졌다면 `D:\JST`에서 `npm run dev`를 실행합니다. 모델은 로컬에 저장돼 있어 열람과 동작 재생에 PINOC 로그인이나 추가 생성 비용이 들지 않습니다.

`.vsplat`은 뼈대 가중치를 포함하는 Gaussian splat 파일이며 일반 인체 메시 GLB·FBX가 아닙니다. 다른 프로젝트에서는 [Viggle Splat Engine](https://viggle.ai/pinoc/app/plugin)이 필요합니다. 함께 들어 있는 GLB는 몸체가 아니라 호환 뼈대 동작입니다. 이 ZIP은 모델·동작·원본 자료 묶음이며 웹 앱 전체나 일반 3D 편집기용 메시를 포함하지 않습니다.

## VR에 사용하기 전 남은 일

정면·측면·후면과 얼굴 비교를 직접 보았고, 대기·걷기·달리기, 모델 왕복 전환, 모바일을 headless Chromium에서 확인했습니다. 기존 모델의 복구 경로까지 포함한 기능 검사 7개와 빌드가 통과했습니다. 토큰 갱신 경로는 실제 연결 복구 및 별도 오프라인 검사 3개로 확인했습니다.

단발·흰 U넥·차콜 치마의 전체 형태와 색은 유지됩니다. 원본에 비해 얼굴의 피부결과 머리 잔가닥이 부드러워지고, 손가락·신발 리본·상의 잔골지·스타킹의 촘촘한 질감이 뭉개지거나 단순화됐습니다. 상의 목선·치마 밑단에도 작은 형상 차이가 있습니다. 동작을 재생하는 시제품으로 채택하며 정밀한 원본 복제라고 평가하지 않습니다.

이 단계는 움직이는 3D 아바타 시제품입니다. HMD 연결, 양안 시차, 눈 위치와 시야각, 1인칭에서의 머리 가림 처리, 손 추적, 실제 VR 동작은 검증하지 않았습니다. 근접 얼굴·손·얇은 옷 가장자리는 원본 이미지와 비교해 사용 가능 여부를 판단해야 합니다.

동작 출처는 PINOC 공식 무료 라이브러리입니다. Standing Idle `1cbf45b5-5abe-4a88-97cd-a1a21da60d7b`, Walking `32d71c7f-e88a-4d1f-9c0c-1fde2da5f060`, Running `32c1d7ba-29d6-466c-a2bc-56ff17ca4d1a`를 기존 저장 파일에서 재사용했습니다.
