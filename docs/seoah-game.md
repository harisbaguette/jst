# 서아의 오후

저장된 단발 여성 캐릭터로 플레이하는 작은 1인칭 탐색 게임이다. 흰 불투명 U넥 긴팔, 차콜 치마, 검정 스타킹과 플랫을 입은 현재 모델을 사용한다. 추가 유료 생성이나 PINOC 로그인은 필요 없다.

## 시작

- 개발 서버: `npm run dev` → http://127.0.0.1:5178/game.html
- 빌드: `npm run build`. `dist/`에 게임과 기존 뷰어가 함께 생성된다.
- 빌드 실행: `Start-Game.cmd` 또는 `python scripts/serve-game.py`. Python 3가 있는 PC에서 별도 패키지 설치 없이 http://127.0.0.1:5180/game.html 을 연다. 실행 창을 닫으면 서버가 종료된다.
- 다른 정적 웹 서버에서도 `dist/`를 사이트 루트로 제공하면 된다. HTML 파일만 더블클릭하는 `file://` 실행은 지원하지 않는다.

## 플레이

몸을 내려다보기 → 전신 거울 확인 → 창가 책상에서 열쇠 챙기기 → 뒤쪽 현관문에서 외출 완료. 완료 뒤에도 방을 자유롭게 돌아다니거나 처음부터 다시 할 수 있다. 실패 시간 제한과 점수 경쟁은 없다.

| 입력 | 동작 |
| --- | --- |
| WASD | 걷기, 좌우 이동 |
| 화면 드래그 / 방향키 | 시선 조절 |
| B | 몸과 발끝 내려다보기 / 앞보기 |
| E | 가까운 거울·열쇠·문과 상호작용 |
| R | 거울 가까이에서 전신 한 바퀴 회전 |
| Esc | 일시정지 |

설정에서 감도·효과음·마우스 시선 고정을 선택할 수 있다. 작은 터치 화면에는 이동 버튼이 표시된다. 터치 드래그로 시선을 조절한다. 이동·단계는 브라우저에 자동 저장되며, 저장을 차단한 환경에서는 이번 창 안에서 진행할 수 있다.

## 구현 범위

캐릭터의 눈높이에서 몸을 보고 걷는 **데스크톱 브라우저 체험판**이다. WebXR, VR 헤드셋·컨트롤러, 손 추적, 전신 IK, 손으로 물체 잡기, 의상 교체는 구현하지 않았다. 열쇠는 가까이서 E를 누르는 상호작용이다. 성별에 따른 생리나 사회적 경험을 시뮬레이션한 게임은 아니다.

전신 거울은 현재 카메라 위치에 따른 비대칭 투영으로 방과 동일한 캐릭터를 매 프레임 반사한다. 거울용 전신과 1인칭용 몸이 **동일한 실시간 뼈대**를 공유한다. 눈앞을 가리는 머리·목·머리카락은 1인칭용 복사본에서만 가린다. 원본 `.vsplat` 파일은 수정하지 않는다. 내려다볼 때는 카메라를 조금 앞으로 이동시켜 상의·치마·다리·발을 함께 확인하도록 했다.

방과 가구는 PlayCanvas 기하 형태, 목재 무늬와 효과음은 코드로 직접 만들었다. 이동은 방 경계와 가구의 사각 충돌 범위로 제한한다. 기존 무료 대기·걷기 동작을 사용하며, 발 접지나 방향별 보행의 물리적 정확성은 제한적이다. 근접 화면에서 손가락·신발·스타킹이 흐려지는 것은 원본 48,000점 모델에도 남아 있는 한계다.

## 확인 기록

`tests/game.spec.js`는 실제 키보드와 UI 입력으로 4단계 완료·거울 회전·책상 충돌·초점 상실 시 정지·저장 복원·재시작을 확인한다. 추가로 저장 손상·저장 거부, 모델 로드 실패 후 재시도, 걷기 동작 누락, 390px 터치 화면의 이동·취소·드래그를 검사한다. 캐릭터 위치를 강제 이동시켜 완료한 시험이 아니다.

실제 화면은 `output/game/01-start.png`부터 `08-mobile-body.png`, 핵심 경로 기록은 `output/game/playthrough.json`에 저장한다. 시험은 사용자 창을 건드리지 않는 headless Chromium에서 한다. 실제 VR 기기나 사용자 PC의 하드웨어 가속 FPS는 검증하지 않았다.

2026-10-22 최종 검사: 기존 뷰어 7개 + 게임 4개 = **11개 통과**, 프로덕션 빌드 통과. `dist/`를 Python 로컬 서버로 제공하고 외부 HTTP 요청을 차단한 상태에서도 실제 모델·몸·거울 렌더, 포인터 잠금과 Esc 일시정지를 확인했다. 페이지 오류·실패한 요청·외부 요청은 모두 0개다. `output/game/build-verification.json`에 기록했다. 빌드에는 기존 엔진의 큰 청크 및 `node:worker_threads` 브라우저 외부화 경고가 남는다.

전달용 ZIP은 `output/game/seoah-afternoon.zip`이다. 빌드된 게임·뷰어와 모델·동작, Python 실행 도우미, 설명·라이선스·검증 기록을 포함한다. 수정용 소스는 현재 프로젝트에 보관한다.

## 파일

- `game.html`: 게임 진입점과 한국어 UI.
- `src/game/main.js`: 입력·카메라·진행·효과음·복구.
- `src/game/room.js`: 방·가구·충돌·상호작용 위치.
- `src/game/mirror.js`: 실시간 반사와 1인칭 머리 가림.
- `src/game/state.js`: 버전 있는 저장과 검증.
- `public/characters/vr-woman-opaque.vsplat`, `public/motions/idle.glb`, `walk.glb`: 재사용 에셋.

출처와 원본 생성 조건은 루트 `ASSETS.md`에 있다.
