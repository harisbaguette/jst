# Benan 심사: 실사 캐릭터 목표는 아직 미달

**캐릭터: 4.70 → 5.68 / 10, REJECT.** 화면 표시와 오류 복구는 개선했지만 원본 얼굴 유사성·실사감은 부족하다.
**연구 산출물: 9.03 / 10.** 원인 분리, 반증 실험, 공식 자료와 실행 가능한 후속 제작 기준을 갖췄다. 연구 점수로 캐릭터의 불합격을 상쇄하지 않는다.

## 범위와 기준

L 규모. 소스·문서·설정 16개(`index.html`, `src/` 3개, `public/character.json`, `tests/` 2개, `scripts/probe-*` 2개, README, ASSETS, 이번 연구·실험·프롬프트·심사 문서 4개, `.gitignore`)와 관련 이미지·모델·실행 기록을 대조했다. 계정 인증과 기존 OAuth 도구의 전면 감사, 다른 3D 제작 도구의 설치·제작은 범위에서 제외했다.

요구는 원본과 닮은 실사급 한국인 성인 여성 캐릭터, 실사감 개선 방법 연구, 심사, 커밋·푸시다. 캐릭터 기능만 성공해도 되는 과제로 낮추지 않았다. 원본 사진은 계속 기준으로 사용했다.

연구 채점표는 출처 25%(9), 반증 22%(9.5), 측정 18%(8.5), 추론 15%(9.2), 관점 10%(8.5), 쓸모 10%(9.3)를 적용했다. 사용자에게 중요한 닮음, 제작자가 고칠 수 있는 범위, 렌더링·연구 측면의 입력 조건을 비교했다. 단일 인물·생성 1회 추가라 통계적 우열·유사도 퍼센트·시간 추세를 만들지 않았다. 각 제품의 기능은 해당 공급사 원문으로 확인했지만, 그 기능마다 독립적인 3개 성능 실험을 확보한 것은 아니다.

항목 점수는 내부 시각·실용 평가이며 객관적 얼굴 인식 점수가 아니다. 가중 합산은 Python으로 계산해 [review-scores.json](../output/research/review-scores.json)에 저장했다. 연구의 수정 전 독립 산출물은 없어 이전 점수는 부여하지 않았다.

## L 규모 시나리오 검토

- **입력·오용:** 동작 이름은 `textContent`, 모델 선택지는 `Option`으로 넣어 HTML 문자열을 실행하지 않는다. 현재 manifest는 저장소의 고정 자료다. 공개 업로드 서비스·인증·결제는 없으므로 가상의 사용자 권한 우회 테스트를 덧붙이지 않았다.
- **장애:** 걷기 GLB 404에서는 캐릭터와 달리기가 살아 있어야 한다. 모델 404에서는 재생 버튼과 다운로드가 사라지고 재시도로 복구돼야 한다. 두 시나리오를 실제 라우트 주입으로 확인했다.
- **실패를 가정한 재검토:** ① 다른 얼굴을 합격으로 보고할 위험 → 원본 대조를 별도 기준으로 고정. ② 버퍼 해상도 때문에 형상과 선명도를 혼동할 위험 → 같은 모델·시점으로 실험. ③ 추가 생성비만 쓰고 개선 없는 위험 → 1회 10크레딧으로 제한, 실패 결과와 잔액 보관.
- **규모:** 10~100 캐릭터 동시 렌더는 이 한 캐릭터 뷰어의 검증 범위가 아니다. full은 2.72배 용량인데 이 얼굴의 개선 근거가 없어 기본값으로 쓰지 않았다. 렌더 버퍼는 약 600만 픽셀로 제한한다. 모바일 하드웨어 성능을 추정 수치로 만들지 않았다.
- **첫 사용:** 전신과 얼굴 비교를 화면에서 바로 선택하고, 모델 선택지에 실험임을 표시한다. 실패한 동작 이름과 재시도를 제공한다. 데스크톱·390px 폭 캡처를 확인했다. 원본 확대는 해상도 복원이 아니라 비교임을 보고서에 명시했다.

연구·표시·복구 개선은 완료했다. 남은 핵심 작업은 원본을 기준으로 얼굴 형상·재질을 재제작하고 근접·다각도·표정 장면에서 다시 합격시키는 것이다. 후속 제작 범위는 [연구 보고서의 합격 기준](realism-research.md#다음-제작의-합격-기준)에 고정했다. 이번 변경은 그 완성본이 아니다.
