# 서아의 오후 · 실행 묶음

흰 상의와 짧은 차콜 치마를 입은 단발 여성 캐릭터로 걷고, 자신의 몸과 전신 거울을 확인하는 1인칭 브라우저 게임입니다.

## 실행

1. ZIP을 폴더에 모두 풉니다.
2. Python 3가 설치된 Windows PC에서 `Start-Game.cmd`를 실행합니다. 이 작업 PC에는 Python이 준비되어 있습니다.
3. 브라우저에서 게임이 열립니다. 실행 창은 플레이하는 동안 열어 두세요. 끝나면 창을 닫습니다.

직접 실행하려면 폴더에서 `python scripts/serve-game.py`를 사용합니다. 기본 주소는 http://127.0.0.1:5180/game.html 입니다. 같은 게임이 이미 실행 중이면 해당 주소를 다시 엽니다. 다른 프로그램이 포트를 쓰고 있다면 `python scripts/serve-game.py --port 5181`로 실행하세요.

Node·npm 설치, PINOC 로그인, API 키, 생성 크레딧은 필요 없습니다. Python을 쓰지 않을 경우 다른 정적 웹 서버로 `dist/`를 사이트 루트에 제공할 수 있습니다. HTML만 더블클릭하는 방식은 지원하지 않습니다. 이 묶음에는 빌드된 게임과 기존 캐릭터 뷰어가 함께 들어 있습니다.

## 조작

- WASD: 걷기
- 화면 드래그 또는 방향키: 시선 조절
- B: 몸 내려다보기 / 앞보기
- E: 가까운 사물과 상호작용
- R: 거울 앞에서 한 바퀴 회전
- Esc: 일시정지

몸 확인 → 전신 거울 → 창가 책상의 열쇠 → 뒤쪽 현관문의 순서로 진행합니다. 완료 후 자유롭게 둘러보거나 다시 시작할 수 있습니다. 진행은 브라우저에 자동 저장됩니다. 설정에는 시선 감도·효과음·마우스 시선 고정이 있습니다. 터치 기기에서는 이동 버튼을 사용하세요.

데스크톱 브라우저 체험판으로, VR 헤드셋·손 추적·의상 교체는 포함하지 않습니다. 근접 시 손가락·신발·원단의 선명도는 원본 3D 에셋의 제약을 받습니다. 외출 완료는 이 방에서의 짧은 플레이 종료이며, 별도의 야외 맵은 없습니다.

## 제작 자료

`ASSETS.md`는 원본 프로젝트의 생성·재사용 이력입니다. 그 안의 원본 이미지·연구 폴더 링크는 실행 묶음에 포함되지 않은 자료를 가리킬 수 있습니다. `LICENSES/`에는 사용한 엔진·빌드 도구의 라이선스를 보관했습니다. `verification/`에는 실제 입력 플레이와 빌드 검증 기록이 있습니다. 게임 실행은 인터넷이나 외부 서비스에 자료를 업로드하지 않습니다.
